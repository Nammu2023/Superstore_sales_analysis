# Superstore Sales Analysis

## Project Overview
This project analyzes transactional sales data from a Superstore dataset to identify revenue trends, regional performance, and category-level insights using Google Sheets.

## Tools Used
- Google Sheets
- Pivot Tables
- Data Cleaning & Transformation
- Time-Based Aggregation
- Line Chart Visualization

## Analysis Performed
- Total Sales by Category
- Total Sales by Region
- Monthly Sales Trend (Time Series Analysis)

## Key Insights
- The Technology category generates the highest revenue contribution.
- The West region accounts for the largest share of total sales.
- Sales demonstrate a steady upward trend with observable seasonal peaks.

## Repository Structure
- `superstore_sales.csv` — Raw dataset
- `Superstore_Sales_Analysis.xlsx` — Cleaned data, pivot tables, and visualizations

## Conclusion
This analysis highlights revenue distribution across product categories and regions while identifying overall sales trends over time. The project demonstrates practical data cleaning, aggregation, and visualization techniques applicable to business analytics scenarios.
