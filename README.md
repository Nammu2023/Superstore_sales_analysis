# Superstore Sales Analysis

## 📌 Project Overview
This project analyzes transactional sales data from a Superstore dataset 
to identify revenue trends, regional performance, and category-level insights 
using Google Sheets.

## 🛠 Tools Used
- Google Sheets
- Pivot Tables
- Data Cleaning & Transformation
- Time-based Aggregation
- Line Chart Visualization

## 📊 Analysis Performed
- Total Sales by Category
- Total Sales by Region
- Monthly Sales Trend (Time Series Analysis)

## 📈 Key Insights
- Technology category generates the highest revenue.
- West region contributes the largest share of total sales.
- Sales show an increasing trend with noticeable seasonal spikes.

## 📁 Repository Structure
- superstore_sales.csv → Raw dataset
- Superstore_Sales_Analysis.xlsx → Cleaned data, pivots, and visualizations

## ✅ Conclusion
The analysis provides business insights into sales distribution 
across categories and regions while identifying overall revenue trends.
